# 小小领航员版本记录

## 1.4.2 — 2026-10-17

安装包瘦身版。**功能与 1.4.1 完全一致，只改打包方式**：安装包从 597 MB 降到约 313 MiB。

### 打包

- **WebView2**：离线运行时（约 180 MB）改为微软官方 Evergreen Bootstrapper（约 2 MB）。已有 WebView2 的电脑安装时不联网，缺少时才联网补装。
- **语音**：安装包内语音由 24 kHz 母带派生为 16 kHz（`scripts/resample_pack.py`）；独立语音包附件仍是 24 kHz 母带。
- 未改动：问答逻辑、界面、遥测、语音识别（ASR 仍为 16 kHz 模型）。

### 验证

- 132 项测试通过。
- 合并语音库 851 msgId / 3,074 条音频的 16 kHz 发行包逐条校验为 16 kHz·16-bit·单声道，无损坏。
- WebView2 窗口冒烟测试通过；静默安装、启动、卸载通过，用户设置与日志保留。

## 1.4.1 — 2026-10-15

语音包人工校准版。依据逐条校对表（205 条）重录 203 条音频，用同一音色（小何 2.0）与同一套裁剪、响度处理；**问答逻辑、界面与遥测代码本版没有改动**。

### 语音包校准

- **术语统一**：前导车 → 安全车、裁判 → 赛事干事、暖身 → 热身、`两 wide` → `two wide`。
- **去掉句尾语气词**（嘿／捏／喔）与拖音，紧急播报更干净；`SPCC_YELOUT_RACE`、`SPCC_PACESPEED`、`SPCC_UCRULE_*` 等一批判罚与旗语同时改写。
- **少数播报改成更有情绪的版本**：`SPCC_DAMBAD`、`SPCC_CANTFIXOVER`、`SPCC_DQRECKDR`、`SPCC_DIG`、`SPCC_UWON`、`SPCC_COMPFIELD_*` 等。
- 音档 2,498 → **2,496 条**：`SPCC_ROLLINGSTART`、`SPCC_PACEIN_RESTART` 各删掉一条改后与同组重复的说法（合并后该 msgId 变体数 6 → 5）。
- 合并后语音库：851 msgId / 3,074 条变体；有声音的 msgId 738 个、刻意静音 35 个不变。

### 版本号

从这一版起，**语音包与安装包共用同一组版本号**（此前语音包单独走 2.0.x）。本版安装包与独立语音包压缩档都是 1.4.1。

### 验证

132 项 unittest 全绿；`check_pack` 851 msgId / 3,074 条变体文件齐全；`audit_offline` 3,074 条音频全部 24 kHz·16-bit·单声道、0 错误、无缺失素材；短语库自检 1763/1763、鲁棒性 92.0% 命中且 0 错意图。重打包前后比对：除本次校准的 203 条外，其余音档位元一致；只有 2 条多余变体被删除。

## 1.4.0 — 2026-10-14

依据当天 31 条实测反馈与一场 AI 正赛实录（`audit/race-20261014-220924/`）修订问答与遥测。

### 新增能力（配同音色录音，24 类六变体 / 139 条）

- **处罚三态分开播报**：`furled`（切弯占了便宜，要减速把优势还回去）、`black`（必须进站受罚，只说指示不解释原因）、`disqualify`（资格没了，跑完收工）。实测一场比赛里 `furled` 反复出现 8 次、`black` 一次都没出现。
- **没有有效圈**：完成圈数但圈速全是 0/−1 时，播"目前還沒有有效圈"，不再含糊拒绝。
- **这台车没有这项设定**：车没这项配置时用俏皮话术说明，和"读到了但没录语音"分开。
- **赛道橡胶五档**：读 session YAML 的 `SessionTrackRubberState`（实测值 `moderately high usage` / `high usage`）。
- **拒绝分三层**：没听清 / 能做但还没做（"专心比赛"）/ 读不到。
- **油耗按口径分开**：平均油耗照旧；当前实际油耗读 `FuelUsePerHour`；两者的差按每圈折算后播报。
- **离指定名次的差距**："离第三名大约差 1.8 秒"、"离组别第一…"，组别第一与全场第一名分开。
- **对手名次**："前車目前第 3 名。"

### 意图层止血（不新增录音的那批）

现实时间、备用轮胎、处罚原因/规则解释一律拒绝；前车是第几名不再播成自己的名次；还有多久会下雨不再播成比赛剩余时间；前车最近一次进站不再播成"油够跑到完"；我这圈极速不再播成"当前圈已用时间"；引擎模式不再播成变速箱挡位。

### 遥测修复

胎温改读 `LFtempC*`（原来读的 `LFtempL` 并不存在，胎温一直是空）；解出 `furled` / `dq_scoring_invalid` 旗位；新增 `CarSetup` 展平读取（MX-5 在 `AntiRollBar`、保时捷在 `ArbSetting`）与"我是否在赛道上"判定（不在赛道上不再算前后车差距）。

### 界面

「问答记录」页新增**导出运行日志**按钮：把日志打成 zip 并附一份环境说明，方便随 bug 反馈提交。

### 短语库

新增 `refuse_phrases` 显式拒绝清单（拼接拼音通道对共享长拼音子串过宽，「现在几点了」对「abs现在几档」能到 0.80）。越界句 11/11 拒绝。

### 验证

132 项 unittest 全绿；`check_pack` 851 msgId / 3076 变体文件齐全；`audit_offline` 3076 条音频全部 24 kHz·16-bit·单声道、0 错误、无缺失素材；短语库自检 1763/1763、越界句 11/11、鲁棒性 92.0% 命中 0 错意图。

### 待办（未完成，不要当已实现）

单圈最高速度与对手进站历史仍需自建派生；引擎模式的播报待车种核验；`AST_REFUSE_HEARD`/`AST_REFUSE_CANT` 各补 3 条变体要重建 assistant-extra 包；进站全流程与雨地尚未实测。

## 1.1.0 — 2026-10-13

依据官方 Black Box 和车辆手册补齐日常遥测问答，新增 61 类六变体回复和 14 条共享单位，共 380 条同音色音频。数值与单位来自对应 SDK；燃油和邻车估计明确标注，轮胎冷压/历史读数分开，未提供的数据拒绝。

加入 SDL2 直接方向盘按键采集、后台读取、稳定设备匹配与热插拔提示。版本区显示用户原图四个 logo。原生窗口固定为无边框，加入最小化/关闭和品牌区拖动。

103 项回归测试通过，虚拟 128 按钮方向盘验证通过；所有 2,895 条 WAV 与播报素材完整。真实按钮、麦克风和原生交互验证边界见工作区报告。

## 1.0.1 — 2026-10-13

修复缺少 SDK 时自动使用模拟数据、错误的车损和轮胎回答、前后车方向混淆、缺失燃油策略数据仍报油够、无依据播报维修区开放等问题。无法确认或尚无对应素材的内容明确拒绝。

补齐实际运行依赖及 SDK 打包收集；修复相对路径、窗口启动失败的清理、无窗口模式退出。新增 57 项回归测试和全部 WAV/路由/历史 ASR 检查工具。详细结果与未实现范围见工作区《全面审查报告.md》。
