# v1.6.4

发布日期：2026-11-05

v1.6.3 的收尾补丁，只修一处误杀：

- **内容闸不再把遥测事实当成操作建议。** 上一版为防止模型给出改车/调校指令，
  对包含「打开/关闭/关掉」的回答一律拒答；结果像「维修区已关闭」「DRS 已打开」
  这种纯事实描述也被误杀。现在这类开/关词必须带祈使语气（把/请/帮我/建议/
  应该/记得…）才判为操作建议；「把 TC 关掉」这类真正的指令仍然拒绝。
  强操作动词（调软、调硬、改成、更换…）的判定不变。

## 升级说明

覆盖安装即可，用户配置、日志、学习库与语音包都会保留。安装包未代码签名，
请用发布页的 `SHA256SUMS.txt` 核对。
