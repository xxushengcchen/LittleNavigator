## 新增：知识库页面

一个只读的诊断页面，回答两个问题：这句话会连到哪里，以及哪类问法还空着。

- **意图图谱**：左侧意图、中间遥测字段组、右侧播报方式，连线表示真实链路。点节点后其余连线压暗，相关字段与播报方式保持高亮。
- **问法矩阵**：14 个意图 × 6 类问法语义的计数矩阵，用颜色深浅表示密度。
- **共用详情**：示例问法、问法分布、读取字段、播报方式；选中状态在两种模式之间保留，`Esc` 取消。
- **筛选**：全部 / 问法最多 / 可疑样本 / 缺口，也可按意图、字段或问法搜索。

![问法矩阵](../ui-preview/v1.5.0/knowledge-matrix.png)

数据不是另抄一份清单，而是在请求时从 `intents_examples.yaml`、真实短语匹配器、规范问句表和路由分支现算，因此改词库后刷新即可看到新结果，缓存 30 秒。本机当前统计：

| 项目 | 数量 |
| --- | --- |
| 意图 | 14 |
| 已载入短语 | 1,772 |
| 原始示例 | 1,791 |
| 规范问句 / 别名 | 69 / 1,504 |
| 规范候选（去重后） | 412 |
| 遥测字段组 | 8 |
| 规则探针 | 75 |

页面**只读**：不播报、不改车、不调模型、不改短语库。

「可疑样本」只报规则问题，不把数据缺失当缺陷：

- **误判**：命中了 A 而 A 的规则分支答不了，但排第二的 B 受理这类问法。
- **缺对象**：意图正确，但问法本身缺必要信息（如「胎压多少」没说哪个轮）。
- **数据缺口**：拒绝原因是读不到值，单独计数，不列为缺陷。

## 修复：拼音通道导致的问法误判

知识库第一次跑起来时暴露了一个真实缺陷：**「现在几档」被判成 ABS 设置**，命中 `abs现在几档`（1.00），而真正的挡位意图 `query_engine` 只有 0.81，最终答不了。

两条根因同时存在才会出错：

1. 词库里只有「abs现在几档」这类带前缀的写法，没有「现在几档」原句；
2. `pypinyin` 的 `errors="ignore"` 把 `abs` 整个丢掉，于是两句的拼音串完全相同，短问法靠拼音通道白拿满分。

修法对应两处：`intents_examples.yaml` 的 `query_engine` 补入「现在几档」「现在几挡」「现在什么挡位」；`phrase_match._syllables()` 保留拉丁字母和数字，`abs` / `tc` 不再被删除。

| 问法 | 修复前 | 修复后 |
| --- | --- | --- |
| 现在几档 | query_car_settings（1.00，答不了） | query_engine（1.00，可答） |
| abs几档 | query_car_settings | query_car_settings（不变） |
| tc几档 | query_car_settings | query_car_settings（不变） |
| 现在几点了 | 拒绝 | 拒绝（不变） |
| 油还購吗（同音错字） | query_fuel | query_fuel（不变） |

新增 `tests/test_phrase_boundaries.py`（8 项）锁住这个边界。

## 界面细节

- 知识库的矩阵列头改为「示例合计」，并在表下注明「图谱按去重后的短语计数、矩阵按原始示例归类」，避免同一意图两处数字不同被误读成错误。
- 窄窗口里意图节点改为单行（名称在左、条数在右）；矩阵宽度大于图谱，切到矩阵时详情自动落到下方。
- UI 回归不再硬编码版本号，改为与接口返回的版本比对。

## 验证与边界

本轮实际执行：

- 后端单元回归：**547 项通过**（含新增 8 项问法边界测试），2,157 项子测试通过。
- 知识库专项浏览器回归：**12 项通过**（导航、统计来自接口、14/8/3 个节点、只高亮相关连线、切模式保留选择、矩阵单元格联动详情、过滤、`Esc`、只读、三档窗口无横向溢出）。
- 全量界面回归：**16 项通过**，覆盖十一个页面、草稿保留、错误恢复与六种宽度。
- 本地链接与锚点检查：新增文档全部纳入，无失效链接。

未做的事，不当成已完成：

- 知识库只在同版本 Edge 内核里渲染验证，没有在打包后的 WebView2 真机窗口里逐页目视确认。
- 问法分布的分类是关键词启发式，只用于看分布，不参与匹配。
- 冲突检测只覆盖固定探针与规范问句，不代表全部 1,791 条问法都已检查。
- 链路里的遥测来自模拟快照；真实连接时同样问法可能有不同结果。
- 「胎压多少」缺对象属于词库覆盖面，本轮未改；补问法时说清左前/右前/左后/右后即可。

## 安装与升级

下载 `LittleNavigator-1.5.0-Setup-x64.exe`（约 307 MiB，含完整本地模型与语音）。升级前退出旧版，选择相同安装范围与目录；用户配置、日志和状态继续保存在 `%LOCALAPPDATA%\LittleNavigator`。AI、TTS、进站控制默认关闭，已有用户配置沿用。

系统缺少 WebView2 时，安装包内的微软官方引导器需要联网补装。项目安装包未代码签名，可在意完整性时用发布页的 `SHA256SUMS.txt` 核对。
