# 方向契约 — 小小领航员界面重做

> 开发用文档，**不得**进入任何浏览器产物（HTML/CSS/JS 注释、data 属性、模板）。
> 审阅者与文档编写者从这里取契约。

## THESIS

把助手重做成一张**赛前检查卡 + 赛后工程记录**：每一屏是一份作业文档，不是一组浮起
的卡片。拒绝当前「白底 + 蓝色主色 + 同尺寸圆角卡片网格」的 SaaS 仪表盘默认长相——
那是这个类别不假思索就会长成的样子。

## OWN-WORLD

深石墨—孔雀机身（顶栏与左轨）包住纸白工作面。**发丝规分栏，没有浮起卡片**：区域之间
靠一条 1px 线和留白分开，不靠阴影、圆角、白底浮层。数值一律等宽、右对齐、带单位小标。
标签用小型大写 + 字距拉开。一个青绿主色只用于「可操作 / 当前选中」；绿 / 琥珀 / 红
只表达就绪度，绝不拿来装饰。字体走系统栈（Operate 界面的本分），但字号与字重有明确
的六级台阶，而不是通篇 13px。

## STORY

打开的第一眼必须回答：**四个子系统是否就绪、现在能不能开跑**。设置页像填一张工程
表单——标签在左、控件在右、说明在下一行小字。复盘页像读一份赛果记录——一行一条，
时间与来源在固定列上对齐。失败、未配置、离线永远比正常状态更显眼。

## FIRST VIEWPORT

顶栏：左侧产品名与版本，右侧**赛前检查总线**——四个方块（游戏 / 麦克风 / AI / 改车），
每块是「名称 + 状态点 + 状态词」。左轨：分组导航（运行 / 设置 / 工具），组标题是小号
大写。主区：文档式内容，首屏给出「当前会话状态」与「最近一条问答」，大数字在左、说明
在右，靠发丝规分栏。

## FORM

技术文档 / 检查表（候选顺位第 2）。签名动作 = **赛前检查总线**：这四个子系统是本产品
真实的结构——游戏连接、语音监听、AI 接入、改车授权——一个「我能不能开跑」的答案，
在顶栏常驻。

## 为什么不是别的

- 不做驾驶舱 / 仪表盘皮肤：Operate 界面里那是把工具当戏服，布局与控件必须还是
  用户认识的样子。
- 不做计时塔式的深色霓虹：那是这个类别最先想到的方向，等于没选。
- 不做编辑排版式的衬线大标题：本项目没有摄影素材，衬线声明会立刻塌掉。

## FINISH

unreviewed and undocumented is unfinished; this build ends with the finish review,
the verdict, DESIGN.md, and every shipping raster carrying its provenance.
