## 新增：知识库页面

一个只读的诊断页面，回答两个问题：这句话会连到哪里，以及哪类问法还空着。

- **意图图谱**：左侧意图、中间遥测字段、右侧播报方式，连线表示真实链路。点开节点后，相关字段与播报方式保持高亮。
- **问法矩阵**：14 个意图 × 6 类问法语义的计数矩阵，用颜色深浅表示问法数量。
- **共用详情**：示例问法、读取字段、播报方式；选中状态在两种模式之间保留，`Esc` 取消。
- **筛选**：全部 / 问法最多 / 可疑样本 / 缺口，也可按意图、字段或问法搜索。

![问法矩阵](../ui-preview/v1.5.0/knowledge-matrix.png)

页面只读：不播报、不改车、不调模型、不改短语库。数据在打开页面时现算，改过词库后刷新即可看到新结果。

「可疑样本」只提示规则层面的问题，不把数据缺失当成缺陷：

- **误判**：这句话命中了 A，但 A 答不了，排第二的 B 反而能答。
- **缺对象**：意图判断正确，但问法少说了必要信息（比如「胎压多少」没说哪个轮）。
- **数据缺口**：拒绝的原因是当前读不到对应数据，单独计数，不算缺陷。

## 修复

### 「现在几档」不再被误判

「现在几档」之前会被判成 ABS 设置、答不出来；现在会正常回答挡位。同类短问法（如「abs几档」「tc几档」）行为保持不变。

### 修复安装版读不到知识库

首版安装包发布后发现：装完之后知识库页显示「读不到知识库」，而开发时运行服务一切正常。原因是打包后的程序里不包含页面需要的数据文件。

问题已修复并替换了同名安装包。**早前下载过 v1.5.0 首版的用户，请重新下载并覆盖安装**；用户配置会保留。

## 安装与升级

下载 `LittleNavigator-1.5.0-Setup-x64.exe`（约 307 MiB，含本地识别模型与语音）。系统要求 Windows 10 2004+ / Windows 11 x64。

升级前退出旧版，选择与旧版相同的安装范围和目录。用户配置、日志与状态保存在 `%LOCALAPPDATA%\LittleNavigator`，升级和卸载都会保留。

系统缺少 WebView2 时会联网补装（安装包内含微软官方引导器）。安装包未代码签名，可用发布页的 `SHA256SUMS.txt` 核对下载的文件。

## 已知限制

- AI 分析、语音合成与语音改车默认关闭，需要自行申请服务并填写密钥/音色后才会启用。
- 真实麦克风、方向盘按钮、外部 AI/TTS 接口与真实比赛场景仍需在实际使用中验证。
- 知识库中的遥测来自模拟快照，真实连接时同样的问法可能有不同结果。
- 问「胎压」时请说明左前 / 右前 / 左后 / 右后，否则可能因缺少对象而无法回答。
