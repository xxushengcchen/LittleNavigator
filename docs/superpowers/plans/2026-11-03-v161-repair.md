## Review Focus

1. Cross-object/cross-unit numbers that happen to have identical values must not authorize false AI claims (Task6).
2. Cancellation between last validity check and playback/live publication must be atomic; a pending replacement must resolve cancelled (Task7).
3. Missing audio, a false-success window, or a partial output must not produce a publishable artifact (Tasks8/11/15).
4. An upgrade must preserve user-written phrases and old learning originals without automatically trusting them (Tasks6/12/15).
5. Windows paths, Unicode staging paths and boundary-zero values must work independently of host display encoding (Tasks3/8/10/11).
