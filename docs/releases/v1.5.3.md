# 小小领航员 v1.5.3

v1.5.3 修复游戏内 Overlay 的透明背景、拖动/缩放和长回答溢出。

[下载安装包](https://github.com/xxushengcchen/LittleNavigator/releases/tag/v1.5.3) · [使用指南](../guide/user-guide.md)

## 修复

- **白色底彻底去掉。** WebView2 的 WinForms Form 默认底色是灰白，之前只设了页面透明和窗口 alpha，叠在游戏上会露出一大块浅色。现在把 Form 的 `TransparencyKey` 和 WebView2 背景一起设为透明（UI 线程），实测显示/隐藏 Overlay 的同一区域像素完全一致。
- **卡片不再有底色/外框。** 只保留 14px 文字和深色投影，边框只在布局模式显示，不会出现“很大的框”。
- **拖动/缩放真的能用了。** Overlay 页面之前没有拿到 `assistant-token`，拖动请求被 403 拒绝，页面又退回不可靠的 `screenX` 算法。现在页面注入 token，并改为桌面端轮询鼠标位置 + `SetWindowPos` 原生移动/缩放；松手后保存位置和尺寸。
- **长回答不再被裁掉。** 卡片去掉 `max-height`，页面按内容高度请求窗口自动撑高（140–400px，保持 14px 字号），长回答换行完整显示。
- 保留 `Ctrl+Alt+L` 布局模式、`Ctrl+Alt+O` 显示/隐藏、主界面宽高/X/Y/重置设置。

## 安装

下载 `LittleNavigator-1.5.3-Setup-x64.exe`（约 307 MiB）。覆盖安装会保留配置。

## 已知限制

- 布局模式的拖动/缩放手感仍需真实鼠标验收；多屏环境按主屏定位。
- Overlay 仍是纯文字层，没有背景板；游戏画面过亮时文字投影可能不够，可在主界面调透明度或布局模式。
