# DESIGN.md — 小小领航员界面系统

从已建成的界面反向记录，不是先写规范再照着做。改这个项目的人先读这里。

## 场景

**谁的、在哪、什么光**：一位 iRacing 车手，在室内正常光线下，坐在模拟器旁。主场景
**不是**比赛中抬头扫一眼（那时主要靠听），而是**赛前调设置、赛后看复盘**——所以这是
一张作业台，不是一个仪表盘。密度可以高、滚动可以长，但每屏必须一眼看清「我现在是
什么状态、下一步做什么」。

这也决定了明暗：纸面工作区，因为主场景是坐着读和填，不是瞟。

## 签名动作：赛前检查总线

顶栏右侧四个方块，每个 = 名称 + 状态点 + 状态词：

| 块 | 数据来源 | 状态 |
|---|---|---|
| 游戏 | `telemetry.connected` / `sim` | ok 已连接 · warn 模拟数据 · bad 未连接 |
| 麦克风 | `ptt.running` / `ptt.state` / `ptt.error` | ok 待命 · warn 录音中/处理中 · bad 出错 · off 未监听 |
| AI | `ai.enabled` / `configured` / `breaker` / `mode` | ok 白名单/按键触发/全接管 · warn 缺密钥 · bad 已熔断 · off 未启用 |
| 改车 | `car_control.enabled` / `available` | ok 可执行 · warn 未连游戏 · off 未启用 |

这是本产品真实的结构（四个独立子系统），不是装饰。它回答「我能不能开跑」——这个问题
原先散落在五个页面里，要用户自己拼。

## 调色板：蓝 · 绿 · 白

三色分工明确，各管一件事：**蓝是结构，绿是交互，白是地面**。

| token | 值 | 用途 |
|---|---|---|
| `--shell` | `#0B2C4D` | 顶栏、左轨（深蓝） |
| `--shell-2/3` | `#123A61` / `#1A4A78` | 轨内 hover / 选中 |
| `--shell-ink` | `#E9F1F8` | 深底正文（12.42:1） |
| `--shell-dim` | `#9CB6CC` | 深底次要（6.73:1） |
| `--paper` | `#FBFDFE` | 工作区地面（白） |
| `--surface` | `#FFFFFF` | 输入框、行底色 |
| `--well` | `#EFF5F9` | 凹陷面（浅蓝白） |
| `--ink` | `#0C2233` | 纸面正文，蓝黑（15.93:1） |
| `--ink-2` | `#3E5A72` | 次要（7.07:1） |
| `--ink-3` | `#566F84` | 说明小字（5.14:1） |
| `--line` / `--line-strong` | `#DFE9F0` / `#B9CCD9` | 发丝规 / 控件边 |
| `--accent` | `#0B6B52` | **绿**：按钮、焦点、选中、当前页 |
| `--data` | `#1F6E9E` | **蓝**：条形图、图例、数据系列 |
| `--ok` / `--warn` / `--bad` | `#0B6B52` / `#8A5A06` / `#9E2B24` | 状态（纸面） |
| 深底状态点 | `#3BD6A0` / `#E8B04A` / `#F0796B` | 状态（机身） |

**为什么绿是交互、蓝是数据**：绿 = 就绪/可执行，天然适合「点这个」；蓝承担结构
与数据，避免绿色在图表里被误读成「好」。状态色里的琥珀与红是语义必需，不参与
三色体系，只在真正需要警报时出现。

**全部文本 ≥4.5:1**（大字 ≥3:1），九个页面实测零不达标；最低一处 4.83:1。

## 字阶

系统栈（Operate 界面的本分），六档，不滥用：

| 用途 | 字号 / 字重 |
|---|---|
| 页标题 `.ira-vhead h2` | 24px / 600 / -0.015em |
| 问题 `.ira-q` | 19px / 600 |
| 分区标题 | 15px / 600 |
| 正文 | 13px / 400 |
| 控件、次要 | 12px / 400 |
| 标签、说明 | 11px / 600 / 大写 + 0.1em 字距 |
| 大数字 `.ira-num` | 44px（卡内 30px）/ 600 / -0.03em |

数字一律 `tabular-nums` 等宽——这里的数据全是测量值，等宽是功能不是装饰。

## 硬规则

1. **没有浮起卡片。** `.ira-card` 是「上规线 + 留白」的分区，背景透明、圆角 0、无阴影。
   新加内容先问：能不能用发丝规和留白分开，而不是再加一个盒子。
2. **一个主色。** 青绿只用于可操作与选中。不要为了「有颜色」给它加地方。
3. **状态色只表状态。** 绿/琥珀/红出现必须有真实语义。
4. **数字右对齐、单位小写。** 表格化数据用固定列宽，不要靠空格凑。
5. **标签在左、控件在右、说明在下一行。** `.ira-field` 的 132px 标签列是所有设置页的
   对齐基准，别破坏它。
6. **浏览器自带表面也要穿衣服。** 选中色、焦点环、滚动条、光标都在样式里；漏掉这些
   是「组装」和「建造」的区别。
7. **触达面积。** 按钮高 30px，小按钮 24px，输入框 30px——和桌面应用的手感一致。

## 反面（这个项目已经踩过的）

- ❌ 白底 + 蓝色 + 同尺寸圆角卡片网格（2026-10 之前的样子）：那是这个类别不假思索的默认长相。
- ❌ 深色霓虹计时塔：这个类别最先想到的方向，等于没选。
- ❌ 衬线大标题：项目没有摄影素材，衬线声明会立刻塌掉。
- ❌ 把驾驶舱/仪表盘当皮肤：Operate 界面里那是把工具当戏服，布局与控件必须还是用户认识的样子。
