# v1.6.2

发布日期：2026-11-04

这一版继续做**修问题**：在 v1.6.1 之后又核对了一批边界，重点是「看起来能用、但会在特定时机说错话或悄悄改配置」的地方。下面按用户能感知的顺序排列，括号里是审查编号。

## 语音与遥测口径

- **每小时油耗不再当「升/小时」播报。** iRacing 给的是燃油质量流量，旧版按体积流量播出去，还拿它乘圈速和「升/圈」相减，单位对不上、差值没有意义。这类问题现在明确拒答，并提示可以问「每圈油耗多少」；每圈消耗升数、剩余升数、续航照常可用。（T01）
- **组别名次不再整体偏一位。** 结果页的组别名次是从 0 开始数的，旧版把它当从 1 开始直接回填，导致组别第一名被丢掉、第二名冒充第一。现在换算后再用，数值缺失或非法就保持未知。（T03）
- **中途进站的那一圈不再当成干净圈。** 旧版只在开圈时判断一次是否在维修区，中途进站再出来仍算干净圈，AI 分析圈速时会把维修区行驶和停留时间当成你节奏变慢。现在只要该圈任何时刻在维修区或维修位，整圈都记为进站圈。（T05）
- **换场次瞬间不再沿用上一场成绩。** 新场次的会话号在结果页里还查不到时，旧版会回退用「最后一场」的名次、最快圈和赛道状态，形成串场。现在查不到就保持未知。（T08）

## AI 回答

- **动态回答不会被存成固定知识。** 模型回答依赖会过期的数值、却又没给出可复用模板时，旧版会在你没注意的情况下把它当作永久知识保存，下次直接播旧数值。现在只有明确标记为静态的回答才入库，动态或说不清的一律不缓存；这类回答仍然正常显示与播报。（A05）
- **学习库里的模板也要过校验。** 模板填出来的句子以前绕过长度/数据/数字三道检查，模板里写死的数字可以照播。现在和模型回答走同一套检查，不通过就退回模型重答。（A07）
- **模板缺数据时不再猜结论。** 条件里需要的字段读不到时，旧版会落到「兜底分支」给一句确定的话。现在整份模板放弃，交给后续路径处理。（A08）
- **模型返回格式异常时安全降级。** 字段类型不对（比如 `answer` 是数字、`refused` 是字符串）以前可能走错分支或抛异常；现在统一按“这次答不了”处理，不会崩。（A15）
- **输入预算把提示词和问题一起算。** 以前 1500 的上限只约束遥测上下文，一个很长的问题仍会整条发出去；现在超预算直接拒答，不截断问题去猜你的意思。（A18）

## 稳定性与资源

- **外部请求有结构化的失败路径**（v1.6.1 已做的跳转/体积/时限之外）：本机 HTTP 服务限制并发连接数并设置读超时，避免被本机其它进程拖垮。（S04）
- **模型调用有每分钟限额。** 配置里一直有这一项，但生产路径没有门禁；现在每分钟额度用完会明确拒绝，不再无限调用。（A16）
- **缺少音频后端时不再整个启动失败。** 没装 PortAudio 的机器以前连文本问答和 TTS 播放都会导入失败；现在录音后端是可选依赖，缺库时只在你真正要录音时给结构化提示。（R06）
- **退出时一定释放资源。** 控制台 `--once`、语音入口 `--wav`、设备错误或任何早退路径，以前可能留下监听线程与日志句柄；现在所有路径都关闭引擎，且清理失败不会掩盖原始错误。（R13）

## 配置与安全

- **保存配置不再先写坏文件。** 非法值（例如不合法的 TTS 超时）以前会先落盘、再在校验时报错，下次启动直接失败；现在先校验后落盘，临时文件唯一且原子替换；保存失败会恢复原来正在运行的监听。（S07）
- **保存音量不再丢掉其它设置。** 上一轮改成“写入前校验”时引入一个回归：只把界面覆盖层当成完整配置，导致调音量后运行中的模型、密钥、设备等基础设置消失（磁盘上仍在，重载又回来）。现在基础配置与覆盖层按与启动相同的顺序合并。（S07）
- **清掉环境变量里的密钥后不再残留。** 同进程里其它配置曾继承上一次注入的环境密钥；现在环境变量只影响本次加载，不会写进默认值。（S09）
- **非 ASCII 凭据返回 403 而不是 500。** 请求头里塞入非 ASCII 字节时，旧的凭据比较会抛异常并写日志；现在按字节比较，稳定拒绝。（S10）
- **超大整数按配置错误处理。** 畸形的超大数字以前会让配置校验抛 `OverflowError` 变成 500；现在返回可读的配置错误。（S11）
- **语音包路径不能越出包目录。** 除 v1.6.1 已挡的绝对路径与 `..`，现在也拒绝 Windows 的驱动器相对、根相对、UNC 与设备命名空间路径，并在解析后确认仍在包目录内（含真实目录联接场景）。（R11）
- **用 `--config` 跑另一套配置时，学习库也跟着隔离。** 以前两套配置共享同一个学习目录，会互相污染学习到的回答；现在学习库跟随该配置文件所在目录，默认路径行为不变。（A17）

## 界面

- **切「全局交给 AI」不再删掉没保存的草稿。** 切换档位会重绘 AI 面板，以前会把已输入但未保存的接口地址、模型名、密钥一起清掉；现在只改档位，草稿保留。（F03）
- **旧模型列表不会再污染新服务商。** 拉取模型时如果中途换了服务商或改了接口地址，旧响应以前会覆盖新的下拉；现在按代次丢弃并提示重新拉取。（F06）

## 工具

- **文档推荐的短语自检在 Windows 默认 GBK 控制台不再崩溃**，能跑完并给出结果。（Q05）
- **干净克隆后方向盘自检能写出报告**：报告目录不存在时会先创建。（Q17）
- **麦克风纯探测 `--probe` 不再强制要求一个用不到的 WAV 参数**；非探测模式仍然必须给 WAV，并给出可读提示。（Q18）
- **ASR 噪声基准可复现**：噪声种子改为由文件名摘要决定，报告里记录实际使用的种子与算法，换机器/换进程结果一致。（Q19）

## 升级说明

直接覆盖安装即可，用户配置、日志、学习库与语音包都会保留。

- 上一版把「每小时油耗」当成升/小时播报的问答，现在会明确拒答；如果你需要燃油规划，请用「每圈油耗」「还剩多少油」「够跑几圈/多久」。
- 组别名次与中途进站圈的判定变了，历史学习库里由旧版本学到的相关问答可能不再命中——这是预期行为，重新问一次即可。
- 安装包仍未代码签名，请用发布页的 `SHA256SUMS.txt` 核对后再安装。

## 已知限制

- 真实游戏内、真实方向盘与麦克风、以及收费 AI / TTS 服务的行为没有在本次交付中实测；自动化验证使用模拟遥测、假设备与假服务商。
- 审查清单共 99 项，本版之后仍有 55 项未处理（多数是前端细节、运行期并发与构建工具链），逐项状态见仓库内 `docs/superpowers/plans/v161-repair-ledger.json`，不把未修的算作已修。
- 模型与语音素材的精确来源与再分发授权凭据尚未闭环，仍列为发布待办；随包说明只写已能核实的部分。
- 新装、旧版升级与卸载的完整流程需要一台可回滚的隔离 Windows 环境执行，本次未在真实用户机器上做卸载验证。
