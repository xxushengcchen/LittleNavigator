# v1.6.1

发布日期：2026-11-03

这一版主要是**修问题**：上一版之后做了一次完整只读审查，逐项核对服务端接口、语音从按键到播报的整条链路、遥测口径、前端的过期请求、构建与发布脚本。下面只列用户能感知的变化；审查编号对应仓库内的审查记录。

## 安全性

- **模型列表不再接受地址与密钥覆盖。** 以前任何本机网页都能让程序拿着你保存的密钥去它指定的地址；现在改成「带本机界面凭据的 POST，只使用已保存的那一对地址与密钥」，旧的 GET 直接拒绝且不发起任何外部请求。（S01）
- **外部请求不再跟随跳转。** 服务商回 30x 时默认拒绝，不会把 `Authorization` / `X-Api-Key` 转发到跳转目标；请直接填写最终的接口地址。（S02）
- **错误信息统一脱敏。** 上游报错不再把请求细节或密钥片段回显到界面与日志。（S03）
- **日志导出必须手动点击。** 旧的 GET 入口已移除，导出改由界面按钮触发的 POST，带凭据、限频、单文件、限量，失败不会留下半个压缩包。（S05）
- **界面不再允许被其它页面套进 iframe。** 加了 `frame-ancestors 'none'` 与 `X-Frame-Options: DENY`（不影响 pywebview 主窗口和 Overlay）。（S06）
- **布尔参数严格校验。** `running`、`play`、Overlay 布局开关传字符串 `"false"` 一律拒绝，不再被当成 `true`。（S08）

## 语音进站控制

- **不再猜着执行。** 否定、转述、说过去做过的事、数字不完整（负数/指数/区间/小数/多个数量/带单位错误）、把「侧/轴」和单个角位混着说、一句话里出现多个服务——这些都改为明确拒绝，一条广播都不发。（A01–A04）
- **修掉「排除后反而全换」。** 复审发现「换胎不要换左前」会把被排除的左前也一起换；现在这类命令直接拒绝。同时修掉「把前胎都换了」被误当成四条全换的静默扩大范围。（A01）
- **「加满」只在算得整数升时自动发送。** iRacing 广播只收 1–120 的整数升；算出 20.3 升这类真实小数时，软件会告诉你估算值并请你明确说「加 20 升」或「加 21 升」，绝不悄悄取整或夹到上限。（R02）

## 稳定性

- **外部请求按总时长返回。** 不再只靠单次 socket 超时；慢响应会按时放弃，卡住的请求同时最多两个，后续请求有界失败而不是无限建线程。（A13）
- **响应体有上限。** JSON 1 MiB、音频 8 MiB、错误体 4 KiB，声明长度和实际读取双向限制，避免一个异常大响应把一次问答拖死。（A14）
- **剩余时间口径更严。** 0 秒是合法的「时间到」；负数、604800、无穷、NaN、布尔一律当作没读到，数值与口语化时长两个字段一起省略，不会只删一半。（T06）

## 界面

- **监听按钮只有一个事实来源。** 控制台和设置页的按钮统一走真实接口并按返回值同步，不再出现一处「暂停监听」、另一处「启动监听」。（F01/F15）
- **旧预览不能再执行过时指令。** 改过问句之后点执行，只会提示你重新预览，不会拿上一句去改车；执行期间也不会重入。（F02）
- **模型列表与日志导出改用新接口。** 前端已同步，旧入口不可用属预期行为。

## 工具与构建

- **`tools/play_test.py` 修好了。** 删除对早已移除的 `src.duck` 的引用，试播工具重新可用。（Q04）

## 升级说明

直接安装覆盖即可，用户配置、日志、学习库与语音包都会保留。

- 用 AI 分析的同学如果之前填的是带跳转的短地址，请改成最终接口地址（通常以 `/v1` 结尾）。
- 「加满」的行为变化见上文；需要精确升数时请直接说整数。
- 安装包仍未代码签名，请用发布页的 `SHA256SUMS.txt` 核对后再安装。

## 已知限制

- 真实游戏内、真实方向盘与麦克风、以及收费 AI / TTS 服务的行为没有在本次交付中实测；自动化验证使用模拟遥测、假设备与假服务商。
- 模型与语音素材的精确来源与再分发授权凭据尚未闭环，仍列为发布待办；随包说明只写已能核实的部分。
- 新装、旧版升级与卸载的完整流程需要一台可回滚的隔离 Windows 环境执行，本次未在真实用户机器上做卸载验证。
