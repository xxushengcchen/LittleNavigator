# v1.6.3

发布日期：2026-11-05

这一版是审查清单的**收尾版**：v1.6.1、v1.6.2 之后剩下的 54 项也全部处理完，审查报告 99 项里 **98 项已闭环**，仅剩 1 项（模型/音频素材的精确来源与再分发授权凭据）需要外部材料，如实保留在待办里。

## 语音与遥测

- 「组别第一」只在本组里找，不再把别的组的头车当目标。
- 结果页偶尔只回一小部分车辆时，参赛车数不会再被缩小（不会再出现「第 2 名 / 共 1 辆」）。
- 跨线那一帧官方圈速常常还是上上圈的旧值：现在先记未知，几帧内拿到真正的官方圈速再回填（连分段一起补）；一直拿不到就保持未知，绝不拿旧成绩顶替。
- 近邻在跨线那一刻会短暂相差一圈：现在只在「一车刚跨过、另一车还没跨」时允许分段对比，真正被套圈的车仍然拒绝。
- 分段问题不再误伤：只有「把全部分段念一遍」才会拒答；「第二段用了多少」「跟前车分段差多少」正常回答。

## AI 回答

- **学习库更挑剔**：前后车、左右轮、否定说法、上一圈/下一圈、单位、段号、问句里的数字，任何一项对不上就不复用旧答案（宁可退回模型重答）。
- **复盘标记真的能生效**：学习库里的条目有了稳定的复盘 ID，标两次「不对」会真正停用该条目，不会再出现「界面显示已标记、库里没变」。
- **数字闸更严**：负号、单位与字段对不上、分秒跨单位、中文「两」、「问题里提到的数字」被当成答案、浮点长尾，这些绕过方式都被堵上，并新增一道回答内容闸。
- **处罚/日期类问题归入安全禁区**，不会被当成普通分析题交给模型自由发挥。
- **关闭或切换 AI 后，在途的旧回答不会再冒出来**：不会覆盖 Overlay、不会突然出声，也不算模型失败。
- 模板能引用口语化的分秒字段，也能处理多段/嵌套数据；解释不了的模板会被拒绝而不是硬填。

## 运行期稳定性

- 监听线程只负责投递，处理在工作线程里排队：按住说话时不会再「第二次按键丢失」。
- 每个新问题会清掉上一条答案与错误；固定反馈不会再残留上一条 Overlay 答案。
- 改分析键后无需手动重启监听即可生效。
- 方向盘后端异常时会明确上报并结束轮询，不会在「监听成功」的假象下空转。
- 车辆指令的发送与关闭在同一把锁内，关闭返回后不会再发出新指令。
- 语音入口（`--wav` 与 PTT）补齐了 AI 仲裁与后续回答，`all` 档不会无声结束。
- winsound 回退补上了片段间隔与首包回调；自检使用配置里的麦克风与原生采样格式。
- 托盘启动超时会放弃，晚到的线程不再偷偷建图标。

## 界面

- 保存请求回来时不会覆盖你刚改的内容；切换服务预设后地址与模型草稿跨页面保留。
- Overlay 宽高输入范围与后端一致（480–1200 × 140–400），不会再「填了被后端拒绝」。
- 音色/voice 字段不再串写；播放失败会显示后端原因，不会假装成功。
- 知识库选中节点/格子后键盘焦点留在原地（不再掉到页面顶部），选项卡补齐 ARIA 与方向键契约。
- 矩阵小字对比度提升到 4.5:1 以上；小窗口图谱不再把字号压到几个像素，改为内部滚动。
- 日志/统计读取失败会明确报错并可重试，不再伪装成「空数据」；总线在「全部交给 AI」档位显示正确。
- 设备按名字配置时显示该设备本身；整数输入非法时会报错并回填保存值；时间格式不再出现 `0:60`。
- 图表反复刷新只保留一个 ResizeObserver，长时间开着不会越来越卡。

## 构建、工具与发布

- 密钥扫描改为精确白名单：测试用的假 Key 不再挡住扫描，真实密钥仍会被抓；暂存路径支持中文/空格且失败即报错。
- 音频缓存指纹覆盖文案、音色、参数与速率，改文案会真的重新合成；缺文案/缺音频/空包一律构建失败，不再产出残缺语音包。
- 豆包单句 `--text` 恢复可用并有 `--dry-run`；WAV 转换失败会如实失败并在重跑时补齐。
- 音频质检与离线审计按 16k/16bit/单声道契约检查，缺文件或修复失败都算失败。
- 安装器：用户自定义短语库升级不覆盖、卸载不删除；新增可选「同步到 iRacing 游戏目录」任务。
- 随包说明移除了已删除的「压低游戏音量」与旧退出方式。
- 链接自检覆盖当前版本与核心开发文档（31 份文档、137 个链接）。
- 构建新增发行配置闸门：配置里出现内联密钥会直接构建失败，AI 与改车默认关闭。
- 新增 CI 工作流，把工具检查、文档链接、配置闸门、编译与后端测试都跑起来。
- 窗口冒烟测试不再假绿：超时、白屏或复用旧记录都会返回非零。

## 升级说明

直接覆盖安装即可，用户配置、日志、学习库与语音包都会保留。

- 学习库的匹配变严格后，旧库里一些「形似但不同对象」的问答会重新走模型，这是预期行为。
- 复盘标记的条目 ID 变了：旧版本标记过的条目不会被自动迁移，重新标记即可。
- 安装包仍未代码签名，请用发布页的 `SHA256SUMS.txt` 核对后再安装。

## 已知限制

- 真实游戏内、真实方向盘/麦克风/托盘、以及收费 AI / TTS 服务的行为没有在本次交付中实测；自动化验证使用模拟遥测、假设备与假服务商，界面验证使用真实浏览器 + mock 接口。
- 审查清单 99 项中 **98 项已闭环**；剩余 **Q22（模型与音频素材的精确版本、来源与再分发授权凭据）** 需要维护者提供可核实的材料，未完成前不会写进随包说明。
- 需要用户本机环境的验证（新装/升级/卸载全流程、真实硬件按键与音频设备）仍未在隔离 Windows 机器上执行。
- 逐项状态与证据见仓库内 `docs/superpowers/plans/v161-repair-ledger.json`。
