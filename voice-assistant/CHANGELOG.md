# 小小领航员版本记录

## 1.4.4 — 2026-10-19

修 1.4.3 实测发现的 10 个问题，并补回界面里的图标与左上角标记。
**功能范围与 1.4.3 相同，没有新增能力**；1.4.3 的全部开关与默认值保持不变。

### 修复 · 语音改车（这一版最重要）

- **否定指令不再反向执行。** 之前说「取消快修」「不要加油」「别撕膜」，
  软件会分别执行快修、加油、撕膜——完全是反的。现在会发送对应的取消指令。
- **加油数值不再被吞小数点与负号。** `加1.5升` 之前被读成 15 升，
  因为短语匹配的归一化会删掉小数点。现在按原文解析：1.5 就是 1.5，
  负数与 0 明确拒绝，也支持「一点五升」「零点五升」。
- **限定角位不再扩大范围。** 「只换左边轮胎」之前会换四条；
  「换左前胎，不要换右前胎」会把右前也加上。现在前者只换左前左后，
  后者只换左前。认不出具体角位、但话里明显在限定范围时，会明确拒绝，
  不会退回成「四条全换」。

### 修复 · 开关与设置

- **AI / 改车开关保存后立即生效**，关闭也能立刻停用。之前必须重启，
  而且关闭后界面仍显示已启用，容易误以为已经关掉。
- **改车设置读回补齐字段。** 之前界面读不到改车配置，永远显示「关 / 未启用」，
  用户再保存一次就会把正确的开启值覆盖成关闭。

### 修复 · AI 与语音

- **TTS 合成结果真的会播放。** 之前界面显示语音合成成功，实际一声不出。
- **OpenAI 兼容 TTS 的音色生效。** 表单里填 `nova`，之前发出去的仍是默认 `alloy`。
- **识别为空时不再请求大模型。** 之前空录音也会发一次请求，白花钱，
  还会播一条没有内容的回答。

### 修复 · 界面

- **补回界面图标与左上角标记。** 1.4.3 把所有图标占位隐藏了，却没有引入图标库，
  于是导航栏、状态块和左上角标记都是空的。现在内置图标，左上角改为角色头像。
- **意图调试台的预览与实际执行一致。** 之前「加1.5升油」在预览里显示成查油量，
  实际执行却是改车。
- **超长文本提示改对。** 提交过长内容时不再误报「text 为空」，
  改为提示最长 512 字符。

### 验证

- 502 项测试通过（新增 22 项针对上述问题的回归测试）。
- 误杀率 0.0%、安全类拦截零漏放、改车解析 13 条可执行全对 / 19 条做不到全拒。
- 90 条真实场景压力测试零问题、零崩溃。

## 1.4.3 — 2026-10-19

本轮加入 AI 大模型接驳、语音改车与界面重做。**这三项都有开关，默认关闭，
规则型问答的行为与 1.4.2 完全一致**——不配置也能照常使用。

### 新增 · AI 大模型（默认关闭）

规则层答不上时，把你的问题连同一份精简遥测交给大模型回答。

- **用户自带模型**：填 `base_url` / `model` / `api_key` 即可，按 OpenAI 兼容协议调用
  （DeepSeek、火山方舟、月之暗面、本地 Ollama 都行）。软件不绑定厂商、不代付费用。
- **三档接管范围**：`whitelist`（默认，最省）只对白名单意图与「为什么/怎么分析」
  这类问题调模型；`analysis_key` 按住专用分析键才用；`full` 规则答不上就接管。
- **硬上限不可突破**：单次调用 2 s、总预算 3.5 s、输入 1500 token、输出 300 token、
  回答 60 字。配置里写更大的值会被钳制并留日志。
- **三道校验闸**：回答里的每个数字都必须能在本次遥测里找到出处，字段必须在白名单内，
  超长直接拒绝。宁可说「答不了」，也不放行编造的数字。
- **赛后复盘**：本场走过模型的问答会列出来，你可以标记对错。标对的存进学习库，
  下次同类问题不必再调模型。

### 新增 · 语音合成（默认关闭）

AI 回答可以用豆包或 OpenAI 兼容的 TTS 念出来。不配就只有文字——**TTS 失败不会
让你丢失回答**，文字照常显示。

### 新增 · 语音改车（默认关闭）

通过 iRacing 广播消息操作进站服务勾选。

- **能做**：换胎（按角或四条）、加油（可说升数，说「加满」会按当前油量实算）、
  快修、清洁挡风（撕膜）、清空进站设置。
- **做不到**：「轮胎配方（软/硬/雨）」——广播消息里没有这个操作，只能在车内黑框选；
  刹车平衡、TC/ABS、雨刷、方向盘也改不了。
- **三道保护**：只走确定性词表、绝不经大模型、发送后回读 `PitSvFlags` 确认真的生效。
  未启用 / 未连接 / 游戏没受理，都会明确告诉你「没改成」而不是假装成功。
- ⚠️ **语音识别会听错**。说「换左前胎」被识别成「换右前胎」就是换错轮胎。
  建议先在练习赛里试熟再上正式比赛。

### 界面重做

- 深蓝机身 + 白色工作面 + 绿色交互的三色体系，去掉浮起卡片，改为发丝规分栏。
- 顶栏新增**赛前检查总线**：游戏 / 麦克风 / AI / 改车 四个方块，一眼看出能不能开跑。
- 左侧导航按「运行 / 设置 / 工具」分组。
- 全部界面文本通过 WCAG AA 对比度检查（≥4.5:1）。

### 修复

- **降级链落到空处**：`AST_REFUSE_CANT` / `AST_REFUSE_HEARD` 之前只存在于代码常量里，
  语音包没有这两条素材，导致素材缺失时完全静默。已补齐各 6 条变体。
- **拼装连接件文案丢失**：`AST_LAPS_LEAD` 等 5 个 msgId 被代码引用但源文案不在仓库里，
  从仓库重建语音包会让「还剩几圈」这类拼装回答失败。已补 `content/assistant-extra.json`。
- 豆包 TTS 返回的 WAV 头是流式占位（长度字段 `0xFFFFFFFF`），会被解析成 37 小时音频。
  已加 `fix_streaming_wav()` 修正。

### 打包

- 语音包重建：主包 2496 条 + assistant-extra 30 条 + assistant-telemetry 627 条，
  均为 24 kHz 母带；安装包内仍按 v1.4.2 的流程派生 16 kHz。
- 新增两个开发用验收工具（不进安装包）：`tools/ai_bench.py`、`tools/stress_test.py`。

- 合并语音库 851 msgId / 3,074 条音频的 16 kHz 发行包逐条校验为 16 kHz·16-bit·单声道，无损坏。
- WebView2 窗口冒烟测试通过；静默安装、启动、卸载通过，用户设置与日志保留。

## 1.4.1 — 2026-10-15

语音包人工校准版。依据逐条校对表（205 条）重录 203 条音频，用同一音色（小何 2.0）与同一套裁剪、响度处理；**问答逻辑、界面与遥测代码本版没有改动**。

### 语音包校准

- **术语统一**：前导车 → 安全车、裁判 → 赛事干事、暖身 → 热身、`两 wide` → `two wide`。

- **少数播报改成更有情绪的版本**：`SPCC_DAMBAD`、`SPCC_CANTFIXOVER`、`SPCC_DQRECKDR`、`SPCC_DIG`、`SPCC_UWON`、`SPCC_COMPFIELD_*` 等。
- 音档 2,498 → **2,496 条**：`SPCC_ROLLINGSTART`、`SPCC_PACEIN_RESTART` 各删掉一条改后与同组重复的说法（合并后该 msgId 变体数 6 → 5）。
- 合并后语音库：851 msgId / 3,074 条变体；有声音的 msgId 738 个、刻意静音 35 个不变。

### 版本号

从这一版起，**语音包与安装包共用同一组版本号**（此前语音包单独走 2.0.x）。本版安装包与独立语音包压缩档都是 1.4.1。

### 验证

132 项 unittest 全绿；`check_pack` 851 msgId / 3,074 条变体文件齐全；`audit_offline` 3,074 条音频全部 24 kHz·16-bit·单声道、0 错误、无缺失素材；短语库自检 1763/1763、鲁棒性 92.0% 命中且 0 错意图。重打包前后比对：除本次校准的 203 条外，其余音档位元一致；只有 2 条多余变体被删除。

## 1.4.0 — 2026-10-14

依据当天 31 条实测反馈与一场 AI 正赛实录（`audit/race-20261014-220924/`）修订问答与遥测。

### 新增能力（配同音色录音，24 类六变体 / 139 条）

- **处罚三态分开播报**：`furled`（切弯占了便宜，要减速把优势还回去）、`black`（必须进站受罚，只说指示不解释原因）、`disqualify`（资格没了，跑完收工）。实测一场比赛里 `furled` 反复出现 8 次、`black` 一次都没出现。
- **没有有效圈**：完成圈数但圈速全是 0/−1 时，播"目前還沒有有效圈"，不再含糊拒绝。
- **这台车没有这项设定**：车没这项配置时用俏皮话术说明，和"读到了但没录语音"分开。
- **赛道橡胶五档**：读 session YAML 的 `SessionTrackRubberState`（实测值 `moderately high usage` / `high usage`）。
- **拒绝分三层**：没听清 / 能做但还没做（"专心比赛"）/ 读不到。
- **油耗按口径分开**：平均油耗照旧；当前实际油耗读 `FuelUsePerHour`；两者的差按每圈折算后播报。
- **离指定名次的差距**："离第三名大约差 1.8 秒"、"离组别第一…"，组别第一与全场第一名分开。
- **对手名次**："前車目前第 3 名。"

### 意图层止血（不新增录音的那批）

现实时间、备用轮胎、处罚原因/规则解释一律拒绝；前车是第几名不再播成自己的名次；还有多久会下雨不再播成比赛剩余时间；前车最近一次进站不再播成"油够跑到完"；我这圈极速不再播成"当前圈已用时间"；引擎模式不再播成变速箱挡位。

### 遥测修复

胎温改读 `LFtempC*`（原来读的 `LFtempL` 并不存在，胎温一直是空）；解出 `furled` / `dq_scoring_invalid` 旗位；新增 `CarSetup` 展平读取（MX-5 在 `AntiRollBar`、保时捷在 `ArbSetting`）与"我是否在赛道上"判定（不在赛道上不再算前后车差距）。

### 界面

「问答记录」页新增**导出运行日志**按钮：把日志打成 zip 并附一份环境说明，方便随 bug 反馈提交。

### 短语库

新增 `refuse_phrases` 显式拒绝清单（拼接拼音通道对共享长拼音子串过宽，「现在几点了」对「abs现在几档」能到 0.80）。越界句 11/11 拒绝。

### 验证

132 项 unittest 全绿；`check_pack` 851 msgId / 3076 变体文件齐全；`audit_offline` 3076 条音频全部 24 kHz·16-bit·单声道、0 错误、无缺失素材；短语库自检 1763/1763、越界句 11/11、鲁棒性 92.0% 命中 0 错意图。

### 待办（未完成，不要当已实现）

单圈最高速度与对手进站历史仍需自建派生；引擎模式的播报待车种核验；`AST_REFUSE_HEARD`/`AST_REFUSE_CANT` 各补 3 条变体要重建 assistant-extra 包；进站全流程与雨地尚未实测。
